Memoria del Proyecto

Lectura

1. Resumen Ejecutivo

Este proyecto consiste en el diseño y desarrollo de un portafolio web personal bajo una estética "Cyber-Industrial". El objetivo es diferenciar el perfil profesional mediante una identidad visual única, demostrando dominio del código nativo.

2. Objetivos Técnicos

  • Interfaz Inmersiva: Atmósfera reactiva con luces ambientales y efectos glitch.
  • Rendimiento: Carga optimizada mediante código limpio (Vanilla JS).
  • Escalabilidad: Arquitectura CSS modular y variables globales.

3. Implementación Destacada

Retos técnicos superados durante el desarrollo:

  • Motor "Cyber-HUD": Combinación de clip-path y filtros drop-shadow para geometrías complejas.
  • Spotlight FX: Sistema de inyección de variables CSS desde JS para seguimiento del mouse.
  • Navegación: Menú lateral con lógica de auto-cierre y scroll inercial (Lenis).

4. Conclusiones

El resultado es una plataforma progresiva que cumple estándares de accesibilidad y diseño responsivo, actuando como prueba técnica de las capacidades del desarrollador.
